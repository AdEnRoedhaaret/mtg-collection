# MTG Collection

A free program that keeps track of a Magic: The Gathering collection and Commander decks: what you own, what it is worth, where each card is filed, and which decks you can build.

There are two ways to use it:

- **On a PC:** the Windows program. You keep and change your collection there.
- **On a phone:** a web page that shows the collection you saved on the PC.

## On a PC: download the program

Open [the latest release](../../releases/latest) and download `MTG-Collection-Setup-x.y.z.exe`.

- Windows, 64-bit.
- The installer is not signed. Windows shows "Windows protected your PC": click **More info**, then **Run anyway**. Only run an installer that you downloaded from this page.
- A newer version installs over the old one. Your cards and decks stay as they are.

The program tells you when a newer version is published here. It never downloads or installs anything by itself: you open this page and run the installer, as the first time.

## On a phone: open the web page

Open **https://adenroedhaaret.github.io/mtg-collection/** in the phone's browser.

1. On the PC, click **Save backup file**. Put that file where the phone can reach it: OneDrive, iCloud Drive, Google Drive, or a mail to yourself.
2. On the phone, tap **Backup**, then **Open backup file…**, and pick that file.
3. On an iPhone, tap **Share**, then **Add to Home Screen**. The page then opens like an app, and Safari keeps its data.

The phone keeps what you opened, also without a connection to the PC. Changes you make on the phone stay on the phone: they do not go back to the PC. Turn on **View only** under **Backup** if the phone should keep none of them. To see newer cards, save a new backup file on the PC and open it on the phone.

The web page is always the newest version.

## Your data

Your collection and your decks stay on your own devices: as files on the PC, and in the browser's storage on the phone. Nothing is uploaded.

The program and the web page contact these services, and no others:

- Scryfall, for card data, pictures and prices;
- EDHREC, for the "Easy builds" lists;
- Google Fonts, for the typeface;
- GitHub: the program asks once at each start for the number of the newest version, and the web page loads its reference files (stories, themes, card facts, combos, tokens) from this page.
